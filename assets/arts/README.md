# Retutta — Gallery Arts

Upload art images to this folder and they will appear automatically in the website gallery after GitHub Pages updates.

Supported formats: `.png`, `.jpg`, `.jpeg`, `.webp`, `.gif`, `.avif`, `.bmp`.

Name files in numeric order, for example `art-1.png`, `art-2.jpg`, `art-3.webp`. The gallery sorts numbered filenames by number and shows one artwork at a time as an animated slideshow.
